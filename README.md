# Dhruv Mangrola — 3D Artist Portfolio

Static portfolio website. Open `index.html` in a modern browser. No build tools or package installation required.

## Pages
- `index.html` — portfolio home, profile, skills, experience and contact
- `game-ready-creatures.html` — Gate of Abyss creatures and additional creature work
- `human-characters.html` — Zayari and Emberveil Tharisse
- `accubow-vr-animals.html` — AccuBow VR animal assets
- `adhira-apocalypse-seer.html` — character showcase
- `bowling-alley-vr.html` — Bowling Alley VR environment project

All images and the résumé are stored locally in `assets/`. Google Fonts are loaded online.
